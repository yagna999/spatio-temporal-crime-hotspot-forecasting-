## 📌 Overview

**Spatio-Temporal Crime Hotspot Forecasting** is an MSc Computer Science dissertation project developed to analyze historical crime data, identify spatial and temporal crime patterns, forecast future crime hotspots, and detect anomalous crime activities using Machine Learning and Geospatial Analytics.

The project provides data-driven insights that can support law enforcement agencies, urban planners, and public safety organizations in making informed decisions regarding crime prevention and resource allocation.

---

## 🎯 Objectives

- Analyze historical crime data.
- Identify spatial and temporal crime patterns.
- Predict future crime hotspot locations.
- Detect anomalous crime events.
- Visualize crime distribution using interactive maps.
- Support data-driven public safety planning.
